# Canva Code용 히스이 대모험 300장

이 패키지는 300장의 PPTX 파일이 아니라 300개 장면을 가진 인터랙티브 웹앱 코드입니다. HTML 파일 하나만으로 실행되며 36종 일러스트, 스토리, 문제, UI가 포함됩니다.

## Canva Code에서 사용하기

1. Canva 홈에서 코드(Code), 또는 Canva AI → 코드를 엽니다.
2. HTML/코드 파일 가져오기를 지원하는 환경이면 Canva_Code_Hisui_300_Interactive.html을 업로드합니다.
3. CANVA_CODE_마스터_지시문.txt에 적힌 지시문을 Canva Code 채팅에 넣어 기존 로직을 유지하도록 합니다.
4. 본인이 Canva의 미리보기에서 기능을 확인하고, 필요하면 디자인에 사용하거나 웹사이트로 게시합니다.
5. 이번 제작에서는 Canva의 계정 업로드, 미리보기 확인, 게시를 수행하지 않았습니다.

Canva Code에서 HTML 가져오기가 나타나지 않는 계정도 있을 수 있습니다. 이 경우 해당 파일은 독립형 HTML 웹앱으로 동작하며, Canva Code에 동일하게 재구성하도록 지시할 때는 HTML 소스와 지시문을 함께 제공해야 합니다. Canva Code의 AI가 소스의 모든 세부 구현을 그대로 가져온다고 단정할 수 없습니다.

## 핵심 동작

- 300장 목차 검색, 이전/다음, 키보드 방향키·스페이스바, 모바일 스와이프
- 발표 모드: 잠금 없이 자유 이동 / 게임 모드: 정답·선택·전투를 마쳐야 다음으로 이동
- 스타터: 나몰빼미, 브케인, 수댕이 선택
- 찬석/주혜 동행 분기에 따른 첫 번째 신(디아루가/펄기아) 표시
- 총 60개 문제: O/X 20, 주관식 20, 객관식 20, 정답해설 60장
- 월로 포켓몬 6마리 + 기라티나 2단계 HP 보스전
- 팀 HP 이어받기, 피해량, 방어, 회복약 6개, 실패 후 재도전
- 로컬 저장소에 진행·선택·전투·정답 기록을 저장
- 독립형 HTML로 인터넷 연결 없이도 이미지 표시

## 구성 파일

- Canva_Code_Hisui_300_Interactive.html : 실행 코드와 데이터/이미지를 모두 포함한 단일 HTML
- hisui300_data.json : 300개 스토리 화면의 구조화 텍스트와 퀴즈 데이터
- CANVA_CODE_마스터_지시문.txt : Canva Code용 유지 및 변환 요청 지시문
- QA_검사결과.txt : 자동 테스트 요약
- README_캔바_사용법.md : 지금 보고 있는 설명

## 주의사항

이 인터랙티브 앱은 원본 PPTX의 화면 내용을 기초로 다시 디자인한 것으로, 원본 300장에 배치된 개별 이미지·애니메이션을 1:1 복제하지 않습니다. 원본에 있는 89점 평가 시스템과 이 앱의 체험 점수 계산은 동일하지 않을 수 있습니다. Canva에서 직접 디자인을 생성하거나 업로드한 상태는 아닙니다.
