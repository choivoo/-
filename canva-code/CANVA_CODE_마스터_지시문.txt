Canva Code 프로젝트 작업 지시문 — 히스이 대모험 300장

첨부한 Canva_Code_Hisui_300_Interactive.html의 소스와 화면 데이터 300개를 최대한 보존하여 Canva Code의 인터랙티브 반응형 웹 디자인으로 사용해 줘. PowerPoint나 일반 발표 슬라이드 PPTX로 만드는 작업이 아니다.

기존 코드의 기능을 축소·삭제하지 말 것:
1) 전체 300개 장면, 12개 챕터, 목차 검색, 이전·다음, 페이지 진행률, 게임 모드와 발표 모드.
2) 60개 문제와 정답 해설(20 O/X, 20 주관식, 20 객관식), 정답 판정과 점수, 오답 재도전.
3) 나몰빼미·브케인·수댕이 스타터 선택과 각 유형별 보너스.
4) 금강단 찬석/진주단 주혜 분기 선택, 첫 조우 디아루가/펄기아의 동적 표시.
5) 월로의 화강돌, 로즈레이드, 토게키스, 히스이 윈디, 루카리오, 한카리아스 6연전과 기라티나 어나더폼/오리진폼 2연전. 총 8단계 HP 미니게임.
6) 보스전 HP 게이지, 빠른 공격/강공격/방어/회복, HP 승계, 회복약 6개, 리트라이, 승리 게이트.
7) 36종의 내장 일러스트 데이터 URI 사용. 외부 API 의존 금지.
8) 모바일·태블릿·PC 반응형, 스와이프/키보드 조작, 읽기 쉬운 글자, 대비 충분한 색상.
9) HTML의 300장 데이터를 지우거나 축약하지 말 것. 대형 위젯 최적화가 필요하면 동시에 한 화면만 렌더링할 것.
10) Canva 게시나 사용자 계정 업로드 확인은 사용자가 직접 수행할 것.

완료 조건: 1번째부터 300번째 장면까지 접근 가능하고, 퀴즈 60개와 보스전 8단계가 실제로 작동해야 한다. 원작 내용과 별개로 제작한 교육용 HP 미니게임은 원작 게임 시스템이라고 서술하지 말 것.
